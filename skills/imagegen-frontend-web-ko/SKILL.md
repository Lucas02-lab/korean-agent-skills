# 한국어 웹 디자인 참고 이미지

이 스킬은 구현할 웹 화면의 시각적 참고 이미지를 만든다. 실제 코드, 반응형 동작, 접근성 검사를 대신하지 않는다.

1. 서비스, 대상, 화면 목적, 원하는 분위기와 필요한 섹션을 파악한다. 사용자가 지정한 수와 형식을 우선한다. 지정이 없으면 랜딩 페이지는 6개, 전체 웹사이트는 8개 섹션을 기본으로 잡고 결과물 수를 알린다.
2. 각 섹션의 역할을 정한다. 예를 들어 첫 화면은 가치와 행동을, 기능은 사용 사례를, 마지막 화면은 다음 행동을 설명한다. 사용자가 제공하지 않은 고객사, 후기, 수치, 가격은 사실처럼 만들지 않는다.
3. 브랜드 색상, 한글에 적합한 서체 분위기, 여백, 이미지 처리와 버튼 체계를 정해 전 섹션에서 일관되게 쓴다. 한글 문구는 짧고 읽기 쉽게 구성하고, 텍스트 이미지의 오탈자는 최종 화면에서 수정할 수 있도록 별도로 명시한다.
4. 섹션마다 별도의 가로 이미지를 생성한다. 요청한 섹션이 4개면 이미지도 4개다. 한 장에 여러 섹션을 이어 붙이지 않는다. 이미지 생성 도구가 없거나 일부 생성에 실패하면 실제 생성한 결과와 빠진 섹션을 구분해 보고한다.
5. 구도를 섹션의 목적에 맞춰 다양하게 고른다. 중앙 배치, 이미지 위 텍스트, 편집형 비대칭, 좌우 분할 등을 고려하되 반복적인 좌측 문구·우측 이미지 배치를 기본으로 삼지 않는다. 미니멀한 요청에는 과한 장식과 큰 배경 이미지를 강요하지 않는다.
6. 각 이미지에서 시선의 우선순위, 읽기 쉬운 대비, 명확한 주요 버튼, 충분한 여백과 구현 가능성을 확인한다. 여러 이미지는 같은 브랜드로 보이되 화면 구성과 이미지 크기는 단조롭게 반복하지 않는다.
7. 결과를 섹션 이름과 함께 제시한다. 이미지 속 한글, 숫자와 버튼 문구의 정확성 및 실제 기기별 동작은 별도 확인이 필요하다고 밝힌다. 실제 생성하지 않은 이미지를 완성했다고 말하지 않는다.

예시 요청: “한국어 독서 기록 서비스의 첫 화면 한 섹션을 차분하고 따뜻하게 디자인해줘. 가입 버튼을 보여줘.”
